What's included in the implementation

  • ✦ Dark (#0A0A0A) full-screen background, no image needed
  • ✦ White icon logo + MEDISAFE wordmark brand strip at top
  • ✦ Dark raised card (#141414) with rounded top corners for the form
  • ✦ Floating labels above each input field
  • ✦ Password show/hide toggle on both screens
  • ✦ "Forgot password?" link on Login
  • ✦ Login uses email + password (not username)
  • ✦ Signup: First + Last side-by-side, Email, Password, Confirm — no scroll
  • ✦ Inline field validation with red border + error message below field
  • ✦ Loading spinner inside the button (replaces text while loading)
  • ✦ Keyboard-aware: form card nudges up when keyboard opens
